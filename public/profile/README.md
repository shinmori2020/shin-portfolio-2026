# ポートレート画像の置き場（規約）

ここに画像を「置くだけ」で **/profile と トップの About の2箇所**に自動反映されます（コード編集は不要）。
画像が無い間は斜線プレースホルダーにフォールバックします。

## 置き方

```
public/profile/portrait.webp
```

- 対応拡張子: `webp` / `png` / `jpg` / `jpeg` / `avif`（`webp` 推奨）。
  同じ名前で複数拡張子があると webp→png→jpg… の順で最初に見つかったものを使用。
- 差し替えは このファイルを上書きして push するだけ（次のデプロイで反映）。

## サイズの推奨

**1200 × 1200 px 以上の正方形**（WebP 書き出し・300KB 以下目安）。

2箇所で比率が違い どちらも `object-cover` で中央を基準に切り抜くため 正方形で用意するのが扱いやすい。

| 表示場所 | 比率 | デスクトップでの表示幅 | 切り抜かれ方 |
|---|---|---|---|
| `/profile` | 1:1（正方形） | 約 440px | そのまま |
| `/`（About） | 4:5（縦長） | 約 420px | 左右が切られる |

高解像度ディスプレイでは表示幅の2倍が要るため 440px 表示なら **実寸で最低 880px** 必要。
余裕を見て 1200px 角を推奨する。これを下回ると拡大されてぼやける。

被写体は中央に寄せておくと どちらの比率でも切れにくい。

## WebP へ変換する

`scripts/to-webp.mjs` は `public/works/` 専用なので ここでは使えない。
手元の画像編集ツールか sharp で個別に変換する。

```bash
node -e "require('sharp')('入力.jpg').resize(1200,1200,{fit:'cover'}).webp({quality:80,effort:6}).toFile('public/profile/portrait.webp')"
```
